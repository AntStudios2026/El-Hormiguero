# 🐜 El Hormiguero - Ant Studios

**El Hormiguero** es un divertido juego arcade desarrollado en Python con Pygame. Ponte en las patas de una valiente hormiga cuya misión es recolectar la mayor cantidad de hojas posible mientras esquiva a una peligrosa araña, aprovecha potenciadores magnéticos y desbloquea aspectos únicos en la tienda de logros.

## 🎮 Características Principales

* **Jugabilidad Dinámica:** Controla a tu hormiga en un entorno lleno de detalles, recolecta múltiples hojas simultáneamente y mantente alerta ante la persecución de la araña.

* **Potenciador de Imán 🧲:** Encuentra el imán especial que aparece aleatoriamente en el mapa. Al activarlo, atraerá automáticamente todas las hojas cercanas hacia ti y encerrará temporalmente a la araña en una jaula protectora.

* **Sistema de Guardado Automático 💾:** Tu progreso histórico de hojas recolectadas y tu aspecto seleccionado se guardan localmente de forma automática (`progreso.json`).

* **Tienda de Logros y Aspectos (Skins) 🏆:** ¡Acumula hojas para desbloquea hasta **8 aspectos diferentes** para tu hormiga!

* **Pantalla Adaptable:** Escalado automático de resolución que se ajusta de forma nativa a tu monitor manteniendo la proporción visual perfecta.

## 🕹️ Controles

### En el Menú Principal

| Tecla | Acción | 
| ----- | ----- | 
| **`ESPACIO`** | Iniciar una nueva partida | 
| **`T`** | Abrir la Tienda de Logros | 
| **`ESC`** | Salir del juego | 

### Durante la Partida

| Tecla | Acción | 
| ----- | ----- | 
| **`Flechas (↑ ↓ ← →)`** | Mover a la hormiga por el mapa | 
| **`P`** | Pausar / Reanudar el juego | 
| **`ESC`** | Cerrar el juego | 

### En la Tienda de Logros

| Tecla / Acción | Acción | 
| ----- | ----- | 
| **`Rueda del Ratón`** | Desplazarse hacia arriba o abajo en el catálogo | 
| **`Teclas 1 al 8`** | Equipar el aspecto seleccionado (si está desbloqueado) | 
| **`ESC`** | Volver al menú anterior | 

### Pantalla de Game Over

| Tecla | Acción | 
| ----- | ----- | 
| **`R`** | Reiniciar la partida rápidamente | 
| **`T`** | Ir a la Tienda de Logros | 
| **`ESC`** | Salir del juego |

## 🚀 Cómo Descargar y Jugar (Ejecutable `.exe`)

No necesitas tener Python ni ninguna librería instalada para jugar:

1. Descarga la última versión comprimida del juego (`.zip`).

2. Extrae **todos** los archivos en una misma carpeta *(Importante: el archivo `.exe` debe permanecer en la misma carpeta que las imágenes y sonidos para funcionar correctamente)*.

3. Haz doble clic en **`Mi_juego_FINAL.exe`** (o el ejecutable correspondiente) y ¡a jugar!

> **Nota para Windows:** Al ser un juego independiente nuevo, es posible que *Windows Defender SmartScreen* muestre un aviso preventivo. Solo haz clic en **"Más información"** y luego en **"Ejecutar de todas formas"**.
